# PettersonApps — AI Best Practices & Policy

Internal course and reference for using AI safely and effectively across the team.

- **`index.html`** — the course (slide deck): open in a browser, navigate with ← → / Space, `F` for fullscreen, `P` to export as PDF.
- **`guidelines.html`** — the same material as a scrollable reference document.
- **`pms.html`** — **Claude for PMs** (*practice, not policy*): a separate slide deck with practical cases for managers. It's linked from the final slide of the course, so everyone goes through the policy once and PMs continue from there. The same content is in `guidelines.html` (last section).

All files are fully self-contained (fonts and assets embedded) — no build step, no external requests.
